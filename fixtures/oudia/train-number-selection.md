# 列車番号指定の確認

`train-number-selection.oud2` をコピーして使用してください（保存は元ファイルを上書きします）。

1. MTRで「進急線北行||快速」を選択します。このサンプルは籠岡→森林公園→さつたば→園戸→富田→追見沢→薄別→砂夢の8駅です。
2. 列車番号に `001M` を入力して経路候補を検索します。
3. 8駅の「001M」が1件表示され、園戸始発の「001M」は除外されることを確認します。
4. プレビューと保存を実行し、対象だけが10:00始発へ変わることを確認します。

- `002M`：同じ8駅の別列車を選択。
- `1M` / `999M`：完全一致する番号がないため候補0件。
- 空欄：従来どおり経路で検索。

MTRの駅構成がこのサンプルと変わっている場合は、コピー側の駅名・駅順を合わせてください。

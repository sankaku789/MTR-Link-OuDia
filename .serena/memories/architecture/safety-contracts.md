# Architecture and safety contracts

- Time: `ServiceTimeMillis` is non-negative `i64`; all additions are checked. Base departure is immutable `10:00:00` (36,000,000 ms); accumulate MTR run/dwell milliseconds without intermediate rounding; only final output conversion uses deterministic non-negative half-up `(ms + 500) / 1000`. Validate rounded arrival/departure order. Internal/preview values may exceed 24h, but current save path rejects any 24h+ timetable until OuDiaSecond representation is proven.
- OuDia losslessness: retain original bytes, UTF-8 BOM, UTF-8 or CP932/Windows-31J encoding, LF/CRLF, unknown lines/attributes and structure. `SourceRange` is a half-open byte interval into the original bytes; do not reconstruct or guess unknown formats. Reject unsupported FileType/encoding, mixed line endings, unknown or ambiguous `EkiJikoku` forms, empty-cell filling, station-slot count changes, stopping/passing-code or track changes.
- Patch safety: each replacement carries original expected bytes and kind; ranges must be in bounds and non-overlapping. Apply against one original byte array; expected-byte mismatch aborts. Compare/guarantee unchanged segments outside permitted time or explicitly selected target-Operation ranges.
- Safe save: reject input/output same path and existing output; read input once and verify its SHA-256 against the session’s expected hash; patch only that read; parse saved bytes before success; write/flush/sync a uniquely-created temp file and finalize without clobbering a race-created output. Original file is not overwritten by default. Failed reparse/diff verification is never success.
- MTR security: permit literal loopback HTTP only (`127.0.0.1`/`::1`), reject credentials/query/fragment/non-root path and remote hosts; reqwest has no redirects and no proxy, connect timeout 300 ms, response timeout 1.5 s, max response 8 MiB. Enumerate OS LISTEN sockets (Windows `GetExtendedTcpTable`), probe bounded candidates with max concurrency 16; never scan all ports or trust HTTP 200 alone—validate MTR JSON envelope and stations/routes.
- GUI/session security: `SessionId`, `CandidateId`, `PreviewId` are application-owned opaque IDs. GUI input contains only selections/paths/policy; it cannot supply patch bytes, SourceRange, or calculated time. Application checks session ownership, revision/staleness, candidate/preview cross-session use and rejects stale state. Tauri commands remain thin wrappers over application use cases.
- Operation policy: if target `Operation*` exists, explicit choice is required; default selection is preserve (raw bytes retained, semantic consistency not guaranteed) or remove only the uniquely identified target train operation range. Full Operation recomputation is out of scope. See `mem:project/overview` for module locations.
